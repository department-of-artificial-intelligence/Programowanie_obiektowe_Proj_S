# Programowanie_obiektowe_Proj_S
Repozytorium kodu realizowanego w ramach przedmiotu programowanie obiektowe projekt (studia stacjonarne).


# Jak używać classlib?
Aby używać classlib, trzeba dodać referencje do tej klasy. Rob się to w ten sposób:

## `dotnet add Korepetycje.csproj reference Korepetycje.Models/Korepetycje.Models.csproj`
